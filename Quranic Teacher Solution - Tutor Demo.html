Optional — technical reference only

This section is for anyone curious what runs underneath. You don't need any of it to use the app.

Recommended technology stack

React-based web app, PDF.js for rendering lesson PDFs, and Supabase for the shared database, login and real-time sync — hosted on a free-tier cloud host.

Authentication

Email/password or "Sign in with Google" — each person only ever sees the classes, lessons and data relevant to their own role.

Database

A standard relational database (PostgreSQL) storing students, classes, lessons, attendance, notes and progress — portable and not locked to one vendor.

Google Drive integration

Least-privilege access: the app only ever sees the specific files a Tutor picks, never the whole Drive. No paid Google Workspace account required.

Google Meet integration

Meet links can be pasted in manually (fastest to launch) or generated automatically via the Google Calendar API in a later phase.

PDF viewer

Every device renders its own copy of the PDF; only page number and highlight position are sent between devices — fast and clear even on a slow connection.

Real-time sharing

A lightweight live-update channel broadcasts the Tutor's current highlight to every connected student in well under a second.

Hosting

Static frontend on a free edge host (e.g. Cloudflare Pages), backend/database on Supabase's free tier.

Security

Row-level access rules, encrypted credentials, HTTPS everywhere, and minimal collection of any student's personal information.

Backup

Managed database backups through the hosting provider; lesson notes and attendance are never stored only on one device.

Scalability

Comfortably handles a solo tutor's full practice; the same architecture scales to multiple tutors later without a rebuild.

Cost & deployment concept

Free or near-zero operating cost for a small tutor

Tutor / Student→ Web App→ Free / Low-Cost Cloud→ Google Drive→ Google Meet

Actual cost depends on usage and each provider's current free-tier limits — this isn't a promise that it stays free forever, but at one tutor's scale it realistically costs $0/month to run.
