# Qaida – Beginners: Curriculum & Lesson Plans

**Source material:** `docs/Noorani_Qaida.pdf` (39 pages) — read in full, page by page,
before writing anything below. Every lesson references real page numbers and real
practice words transcribed directly from those pages. Where the book's own
progression differs from a generic "conceptual" Qaida outline, the book wins
(per the brief's instruction #13) — see "Deviations from the conceptual outline" below.

**Class:** *Qaida – Beginners*
**Purpose:** Introduce beginners to reading the Qur'an step-by-step using this
Noorani Qaida, starting from letter recognition and progressing — exactly in
the book's own order — through joining, vowel marks, madd, tanween, sukoon
rules, tashdeed, Ra/Lam rules, waqf, and the book's final integrated reading
practice, ending ready to begin real Qur'an reading.

---

## How this document is organized

- **14 stages**, each ending in a **review lesson** (except Stage 10, which is
  itself a milestone/checkpoint), matching the book's own natural topic
  boundaries — not the artificial 9-stage sketch in the brief, because the
  actual book interleaves topics differently (Madd comes right after Harakaat,
  before Tanween; Tashdeed comes after the first Sukoon exam; Shamsi/Qamri and
  Lafظ-Allah share a page; Waqf appears twice — once as a basic stop-mark
  lesson right before the first full surah, and again as a full symbol
  reference near the end).
- **51 sessions total**: 39 teaching lessons (one per page of real content,
  since every page is a self-contained Takhti with its own grid + practice
  words) + 11 review lessons + 1 final completion assessment.
- Every lesson follows the **same 8-step structure** (stated once below, not
  repeated 51 times) and uses the same **progress-status vocabulary**.
- "PDF Highlight Focus" tells the tutor what to select/highlight on the Teach
  screen — in this book, that's almost always "the practice-words block,
  read left→right, row by row" or "the grid cell for letter X," since each
  page already isolates its teaching content visually.

### Deviations from the conceptual outline in the brief

| Brief's conceptual stage | What the actual book does instead |
|---|---|
| Stage 3 Harakat → Stage 4 Sukoon → Stage 5 Tanween → Stage 6 Madd → Stage 7 Shaddah | Book order is: **Harakaat (p.7-9) → Madd letters + Khari signs + Leen (p.10-18) → Tanween (p.19) → Tanween/Noon-Sakinah rules: Izhaar/Ikhfa (p.20-22) → Sukoon/Jazm + Qalqalah (p.23-24) → Tashdeed (p.25)**. Madd comes well before Tanween/Sukoon rules, not after. |
| No mention of Ra rules, Shamsi/Qamri letters, or Lafظ-Allah | The book has dedicated pages for **Ra Sakinah & Mushaddadah (p.26)** and **Huroof-e-Qamri/Shamsi + the rule for the word "Allah" (p.27)** — both essential Tajweed-adjacent rules the conceptual outline omitted entirely. |
| Stage 9 "Preparation for Quran Reading" only at the end | The book has the student read **the complete Surah Al-Fatiha** as early as **page 28** (right after basic Waqf marks), then returns to deepen Madd rules and introduces **Huroof-e-Muqatta'at** (p.29-30), then **Meem-Sakinah/Iqlab/Idgham rules** (p.31-34), then **Rasm-ul-Khatt** (Qur'anic spelling quirks, p.35-36) and a **full Waqf-symbol reference** (p.37), before its true final integrated-reading pages (p.38-39, real ayaat from short surahs combining every rule taught). |
| — | The book also runs **short, real Qur'anic phrases as reading tests** far earlier than expected — e.g. page 6's review test already uses phrases like `اِیَّاکَ نَسْتَعِیْنُ` and `فَسَیَکْفِیْکَهُمُ اللّٰہُ`, well before Harakaat is formally taught on page 7. This is the book's own choice (testing letter-recognition using familiar, oft-heard phrases) and is preserved as-is rather than "corrected." |

## Standard lesson structure (applies to every lesson below)

1. **Review** — briefly revise the previous lesson's grid/practice words.
2. **Introduce** — read the new rule/heading aloud, explain in one or two sentences.
3. **Demonstrate** — tutor reads the full grid once, at a measured pace.
4. **Practice Together** — tutor and student read the grid together, row by row.
5. **Student Practice** — student reads the grid and then the practice-words block alone.
6. **Correction** — tutor flags mispronunciations (see each lesson's common-mistake note where the book itself calls one out, e.g. "don't drag out the short vowel").
7. **Homework** — student re-reads today's page 3–5 times before the next lesson.
8. **Progress** — tutor records one of: **Not Started / In Progress / Needs Practice / Completed / Mastered**.

## Progress status vocabulary

- **Not Started** — lesson not yet attempted.
- **In Progress** — first pass done, still hesitant on ≥3 items.
- **Needs Practice** — reads correctly but slowly, or 1–2 recurring errors.
- **Completed** — reads the full page correctly at a normal pace.
- **Mastered** — reads fluently and can apply the rule to *new*, unseen words.

**Default assessment criterion** (unless a lesson states a more specific one):
> Student can correctly identify and pronounce at least 90% of the letters/words
> presented on this page, with correct application of today's rule.

## Stage 1 — Letter Recognition (Huroof-e-Tahajji)

### Lesson 1 — Isolated Letters, Part 1
- **Qaida Topic:** Mufradat (isolated letter forms) — first 20 letters
- **PDF Page:** p.1
- **Objective:** Recognize and correctly pronounce the isolated forms of ا ب ت ث ج ح خ د ذ ز س ش ص ض ط ظ ع غ.
- **Prerequisite:** None — first lesson.
- **Next Lesson:** Lesson 2.
- **Duration:** 30 min.
- **Tutor should teach:** Point to each of the 5 rows of letters on p.1 in turn; name each letter; have the student repeat; drill any letter the student hesitates on individually.
- **Practice Activity:** Student points and names each letter in random order (tutor covers/reveals with a finger) — this is *identical* to the book's own layout, no material needs to be invented.
- **PDF Highlight Focus:** Highlight one row of the letter grid at a time (row-by-row, top to bottom).
- **Expected Outcome:** Student names all 20 letters unprompted.
- **Homework:** Practice naming today's letters for 10 minutes with a parent/sibling.
- **Assessment:** Default criterion (90%).

### Lesson 2 — Isolated Letters, Part 2 + Recognition Test + Joined-Form Shapes
- **Qaida Topic:** Remaining letters (ف ق ك ل ه و ن م ء ي ة) + a jumbled recognition test + the chart showing how letters look at the start/middle/end of a word
- **PDF Page:** p.2
- **Objective:** Complete the alphabet; pass a jumbled-order recognition test; recognize that letters change shape when joined.
- **Prerequisite:** Lesson 1.
- **Next Lesson:** Review 1.
- **Duration:** 35 min.
- **Tutor should teach:** New letters first (top of page); then the **امتحان** (test) block — read it aloud once, then have the student read it unaided; then briefly point out the "shapes when joined" chart as a preview of Stage 2 (don't drill it yet — that's next stage's job).
- **Practice Activity:** Student reads the jumbled-letter test block start to finish without the tutor's help.
- **PDF Highlight Focus:** The امتحان (test) grid — this is the actual pass/fail check for Stage 1.
- **Expected Outcome:** Student passes the test block, naming ≥90% of letters correctly on the first try.
- **Homework:** Re-read the full alphabet (both pages) once daily.
- **Assessment:** Student independently reads the p.2 test block with ≤2 errors.

### Review 1 — Lessons 1–2
- **PDF Page:** p.1–2 (re-read both).
- **Objective:** Confirm full alphabet recognition before moving to joining letters.
- **Duration:** 30 min.
- **What to check:** Random-order naming of all 29 letters; readiness gate — do not proceed to Stage 2 until this is **Completed**.

## Stage 2 — Joining Letters (Murakkabat)

### Lesson 3 — Joining ل ا and ک; connecting ب ت ث ن ی
- **Qaida Topic:** Murakkabat (joined letters), Takhti 2 begins
- **PDF Page:** p.3
- **Objective:** Read 2–4-letter joined combinations, starting with لا/جا/ما/با shapes, then ک-shapes, then ب ت ث ن ی chains.
- **Prerequisite:** Review 1 (must be Completed).
- **Next Lesson:** Lesson 4.
- **Duration:** 35 min.
- **Tutor should teach:** Point out that a letter's *shape* changes when joined but its *sound* doesn't; work down the page block by block (لا group → ک group → ب ت ث ن ی group), reading each printed word (لاجا، لاما، لالب، بلب، کبلت، کابلت، تکث، باتاثانایابس، یسنستستسثجتح).
- **Practice Activity:** Student reads each block aloud after the tutor's demonstration.
- **PDF Highlight Focus:** One joined-word block at a time (the boxed rows on p.3).
- **Expected Outcome:** Student reads all of p.3's joined words without sounding out letter-by-letter.
- **Homework:** Re-read p.3 three times.
- **Assessment:** Default criterion.

### Lesson 4 — Joining ن م ح خ ه ة chains
- **Qaida Topic:** Murakkabat continued
- **PDF Page:** p.4
- **Objective:** Read longer joined words (4–5 letters) mixing ن ب ت ی ث with ج ح خ and with ه/ة endings.
- **Prerequisite:** Lesson 3.
- **Next Lesson:** Lesson 5.
- **Duration:** 35 min.
- **Tutor should teach:** Work down the page's word blocks: نخ‌یخ‌بخ‌بح‌یم‌بم‌نم group → تم‌ثم‌بی‌یی‌نی‌تی group → longer 5-letter words (ثی‌نبل‌تنل‌بیل‌یتل‌ثثل, نبن‌بنن‌تین‌یتن‌ثشن‌نین) → ح خ ج group (حث‌خب‌جت‌تحت‌یحب, صحب‌بخت) → ه/ة group (بة‌یة‌ته‌یهب‌بها‌بهم).
- **Practice Activity:** Student reads each block; tutor flags any letter-shape confusion (especially ی vs ب vs ت vs ث, which differ only in dot placement).
- **PDF Highlight Focus:** The longer 5-letter word rows — these are the hardest on the page.
- **Expected Outcome:** Student distinguishes dotted look-alike letters (ب ت ث ن ی) reliably inside joined words.
- **Homework:** Re-read p.4, focus on the 5-letter rows.
- **Assessment:** Student correctly reads the 5-letter rows with ≤2 dot-placement errors.

### Lesson 5 — Joining د ذ ر ز س ش ص ض ط ظ ع غ ء
- **Qaida Topic:** Murakkabat continued
- **PDF Page:** p.5
- **Objective:** Read joined words using the remaining "non-connecting-after" letters (د ذ ر ز, which never join to the *next* letter) and ه sounds (س ش ص ض ط ظ) and (ع غ ء).
- **Prerequisite:** Lesson 4.
- **Next Lesson:** Lesson 6.
- **Duration:** 35 min.
- **Tutor should teach:** د ذ ر ز group (جد‌خذ‌جر‌خز‌یر‌تن, مد‌کذ‌فر‌مز) — point out these 6 letters never connect forward; س ش ص ض ط ظ group (سل‌شل‌صب‌طب‌ضا, سر‌شق‌ضی‌ظا); ع غ ء group (عز‌غر‌صع‌ضغ‌بعد‌تغد) and the four hamza forms (ء أ ؤ ئ).
- **Practice Activity:** Student reads all three blocks; tutor specifically checks whether the student correctly *stops* joining after د ذ ر ز (a very common beginner mistake is to force-join them to the next letter).
- **PDF Highlight Focus:** The د ذ ر ز block — the "non-connector" rule is the key teaching point of this page.
- **Expected Outcome:** Student never force-joins د ذ ر ز to a following letter.
- **Homework:** Re-read p.5.
- **Assessment:** Zero non-connector errors on a fresh (unpracticed) sentence the tutor writes using the same letters.

### Lesson 6 — Joining ف ق و م + Review Test (real Qur'anic phrases)
- **Qaida Topic:** Murakkabat continued + first real-phrase test
- **PDF Page:** p.6
- **Objective:** Complete the joining-letters stage; read short real Qur'anic phrases using only the letter-recognition/joining skills learned so far (no vowel-mark rules needed yet — these are read as familiar, oft-heard phrases).
- **Prerequisite:** Lesson 5.
- **Next Lesson:** Review 2.
- **Duration:** 40 min.
- **Tutor should teach:** ف ق و م group (قو‌فو‌فقل‌قفل‌یف‌حم, کم‌لم‌تم‌تمت); then the **امتحان** block — familiar phrases `اِیَّاکَ نَسْتَعِیْنُ`, `وَمَا یُدْرِیْکَ`, `لَعَلَّہٗ یَزَّکّٰی اَوْ یَذَّکَّرُ فَتَنْفَعَہُ الذِّکْرٰی`, `فَسَیَکْفِیْکَهُمُ اللّٰہُ`, `قِبْلَتَهُمْ`, `مُسْتَقِیْمٍ بِحِجَارَۃٍ مِّنْ سِجِّیْلٍ`, `فَجَعَلَهُمْ کَعَصْفٍ مَّاْکُوْلٍ`, `لَتُنَبَّؤُنَّ`. Tutor should note these phrases are widely heard already (Al-Fatiha, Al-Fil, etc.) — reading them here is confidence-building recognition practice, not yet rule-based reading.
- **Practice Activity:** Student reads the امتحان block phrase by phrase.
- **PDF Highlight Focus:** Each printed phrase in the امتحان block, one at a time.
- **Expected Outcome:** Student reads the whole test block, joining letters correctly throughout.
- **Homework:** Re-read p.6's test block.
- **Assessment:** Student reads the full امتحان block with ≤3 hesitations. This is the **Stage 2 completion gate**.

### Review 2 — Lessons 3–6
- **PDF Page:** p.3–6.
- **Objective:** Confirm reliable letter-joining before introducing vowel marks (Harakaat) — the single biggest jump in the whole Qaida.
- **Duration:** 40 min.
- **What to check:** Fluent (not sounded-out) reading of any one full page from 3–6, tutor's choice.

## Stage 3 — Harakaat (short vowels: Zabar, Zer, Pesh)

### Lesson 7 — Zabar (Fatha)
- **Qaida Topic:** Harakaat — intro (what Zabar/Zer/Pesh are) + Zabar grid
- **PDF Page:** p.7
- **Objective:** Read every letter with a Zabar (short "a" sound); apply the book's own warning not to drag the sound out.
- **Prerequisite:** Review 2 (must be Completed).
- **Next Lesson:** Lesson 8.
- **Duration:** 35 min.
- **Tutor should teach:** Read the intro text aloud (Zabar/Zer/Pesh are collectively "Harakaat"; alif is never itself vowelled unless it's a hamza-carrier; Zabar's sound is bright/open); demonstrate the full letter-with-Zabar grid; then the مشق (practice) words: دَرَسَ کَسَبَ وَدَعَ عَبَدَ بَلَغَ دَخَلَ وَجَدَ سَجَدَ.
- **Practice Activity:** Student reads the grid, then the practice words; tutor specifically listens for the "don't drag it out" mistake the book calls out.
- **PDF Highlight Focus:** The practice-words block (بottom half of the page) — this is the real test of whether Zabar is understood, not just the grid.
- **Expected Outcome:** Student reads all 8 practice words with crisp, short Zabar sounds.
- **Homework:** Re-read the practice words 5 times, timing for briskness not slowness.
- **Assessment:** Default criterion, plus: no dragged-out vowel sounds.

### Lesson 8 — Zer (Kasra)
- **Qaida Topic:** Harakaat — Zer grid
- **PDF Page:** p.8
- **Objective:** Read every letter with a Zer (short "i" sound), including hamza-with-zer (اِ) forms.
- **Prerequisite:** Lesson 7.
- **Next Lesson:** Lesson 9.
- **Duration:** 35 min.
- **Tutor should teach:** Full Zer grid; then practice words اِبِلِ رَدِفَ حَمِدَ شَهِدَ بَخِلَ سَخِرَ رَحِمَ لَعِبَ, then the second practice row شَرِبَ عَمِلَ بَرِقَ خَطِفَ جَزِعَ سَقِمَ غَشِیَ نَسِیَ; the book's own note: don't drag the hamza-with-zer sound, and don't let it go "muted"/unvowelled.
- **Practice Activity:** Student reads both practice rows.
- **PDF Highlight Focus:** The اِبِلِ row (hamza + zer) specifically, since that combination is the page's flagged trouble spot.
- **Expected Outcome:** Student correctly distinguishes Zabar (from L7) vs Zer sounds when reading mixed words later.
- **Homework:** Re-read both practice rows.
- **Assessment:** Default criterion.

### Lesson 9 — Pesh (Damma)
- **Qaida Topic:** Harakaat — Pesh grid
- **PDF Page:** p.9
- **Objective:** Read every letter with a Pesh (short "u" sound).
- **Prerequisite:** Lesson 8.
- **Next Lesson:** Review 3.
- **Duration:** 35 min.
- **Tutor should teach:** Full Pesh grid; practice words رَسُلُ سُدُسُ فَقِدَ قُتِلَ کَرُمَ عُلِمَ هُدِیَ نَکِسَ, then صُحُفُ وُسِعَ قُدِرَ نُصِرَ; note the book's own caution: don't drag it out, and lips should round/purse slightly for a clean Pesh sound.
- **Practice Activity:** Student reads both rows; tutor checks lip-rounding, not just the sound.
- **PDF Highlight Focus:** The practice-words rows.
- **Expected Outcome:** Student can be given any consonant + any of the 3 Harakaat (Zabar/Zer/Pesh) orally and produce the correct sound.
- **Homework:** Mixed oral quiz with a parent: tutor/parent names a letter + a Harakah, student says the sound.
- **Assessment:** Student passes a 10-item random Zabar/Zer/Pesh oral quiz with ≥9/10 correct.

### Review 3 — Lessons 7–9
- **PDF Page:** p.7–9.
- **Objective:** Confirm all 3 short vowels are secure before introducing long vowels (Madd).
- **Duration:** 30 min.
- **What to check:** Randomized oral quiz across all three Harakaat.

## Stage 4 — Huroof-e-Madd (long vowels: ا و ی)

### Lesson 10 — Alif Madd ("aa")
- **Qaida Topic:** Huroof-e-Madd intro + Alif-madd grid
- **PDF Page:** p.10
- **Objective:** Understand the 3 madd letters (ا و ی) and their rule (madd letter preceded by matching Harakah = long vowel); read the Alif-madd ("aa") grid and practice words.
- **Prerequisite:** Review 3.
- **Next Lesson:** Lesson 11.
- **Duration:** 35 min.
- **Tutor should teach:** Read the intro rule aloud (huroof-e-madd = ا و ی; the alif must be preceded by a Zabar to make an "aa" sound); demonstrate the grid (دَا خَا حَا جَا ثَا تَا بَا ءَا, etc.); practice words زَادَ جَاھَدَ تَابَ خَافَ حَاسَبَ جُنَاحُ شَارَبَ فَرَاغَ خَادَعَ قَاتَلَ صَابَرَ تَعَالَ.
- **Practice Activity:** Student reads the grid, then all 12 practice words, holding the "aa" sound roughly 2 counts longer than a plain Zabar.
- **PDF Highlight Focus:** Practice-words block, emphasizing the elongation.
- **Expected Outcome:** Student audibly distinguishes a plain Zabar (کَ) from an Alif-madd (کَا).
- **Homework:** Re-read practice words, exaggerating the length difference at home.
- **Assessment:** Default criterion.

### Lesson 11 — Ya Madd ("ee") + intro to Jazm
- **Qaida Topic:** Ya-madd grid + first mention of Jazm (sukoon)
- **PDF Page:** p.11
- **Objective:** Read the "ee" sound (Zer + ی); recognize the جزم (sukoon) symbol as a preview for Stage 7.
- **Prerequisite:** Lesson 10.
- **Next Lesson:** Lesson 12.
- **Duration:** 35 min.
- **Tutor should teach:** Ya-madd grid (اِیْ بِیْ تِیْ...); practice words دِیْنِیْ کِتَابِیْ فِیْہِ اَرِنِیْ رَازِقِیْنَ یُوَارِیْ مَفَاتِیْحُ اُجِیْبُ, plus the extended words عِبَادِیْ عَذَابِیْ تَمَاثِیْلُ مَقَادِیْرُ اَخِیْہِ بَنِیْہِ; the page's own footnote on جزم is a preview only — don't drill Jazm as a separate topic yet, that's Lesson 23.
- **Practice Activity:** Student reads all practice words, holding the "ee" sound clearly.
- **PDF Highlight Focus:** The کِتَابِیْ / دِیْنِیْ pair — shows Alif-madd and Ya-madd in the same word, a good discrimination check.
- **Expected Outcome:** Student distinguishes "aa" (L10) from "ee" (this lesson) inside the same word.
- **Homework:** Re-read practice words.
- **Assessment:** Default criterion.

### Lesson 12 — Waw Madd ("oo") + real Qur'anic words
- **Qaida Topic:** Waw-madd grid + first real Qur'anic vocabulary
- **PDF Page:** p.12
- **Objective:** Read the "oo" sound (Pesh + و); apply it to real Qur'anic words (proper nouns and Qur'anic vocabulary).
- **Prerequisite:** Lesson 11.
- **Next Lesson:** Review 4.
- **Duration:** 35 min.
- **Tutor should teach:** Waw-madd grid; practice words نُوْحُ طُوْرُ تُوْبُوْا نُوْرُ یُوْحِیْ یَقُوْمُ قَالُوْا تَکُوْنُ; then the real Qur'anic-word block (this is the page's own extra emphasis — flag it as special): مُسْلِمُوْنَ قَارُوْنَ دَاخِرُوْنَ سَابِقُوْنَ بَاسِطُوْنَ رَاجِعُوْنَ. Point out these are real words the student will meet again in actual Qur'an reading (e.g. رَاجِعُوْنَ from إِنَّا لِلَّهِ وَإِنَّا إِلَيْهِ رَاجِعُونَ).
- **Practice Activity:** Student reads all words; tutor asks if any word sounds familiar from things they've heard recited.
- **PDF Highlight Focus:** The real-word block at the bottom — a motivating "you're already reading real Qur'an words" moment.
- **Expected Outcome:** Student reads all three long-vowel sounds (aa/ee/oo) confidently and can tell them apart on sight.
- **Homework:** Re-read p.12, and ask a parent to recite رَاجِعُوْنَ / نُوْحُ aloud so the student recognizes the connection.
- **Assessment:** Student correctly reads a random mix of aa/ee/oo words drawn from Lessons 10–12 with ≥90% accuracy.

### Review 4 — Lessons 10–12
- **PDF Page:** p.10–12.
- **Objective:** Confirm all 3 madd letters are secure before the "khari" substitute signs.
- **Duration:** 30 min.
- **What to check:** Mixed aa/ee/oo reading quiz.

## Stage 5 — Khari Signs (compact madd substitutes)

### Lesson 13 — Khari Zabar (اٰ)
- **Qaida Topic:** Khari Zabar — a small vertical stroke standing in for a written Alif
- **PDF Page:** p.13
- **Objective:** Recognize that خِیْ (khari) Zabar sounds *exactly* like Alif-madd from L10, just written compactly.
- **Prerequisite:** Review 4.
- **Next Lesson:** Lesson 14.
- **Duration:** 30 min.
- **Tutor should teach:** Explain: this is the *same sound* as Lesson 10, only the alif is "hidden" as a small stroke above the letter (the book's example: ب braced by Khari-Zabar sounds equal to بَا); grid; practice words اٰدَمَ اٰمَنَ مٰلِکِ اٰبَوٰہُ سٰمٰوٰتِ غٰوِیْنَ یُصْلِحُ اِلٰهَنَا هٰذَا کِتٰبُ رِسٰلٰتِ ذٰلِکَ.
- **Practice Activity:** Student reads all practice words, several of which are common names/words (اٰدَمَ = Adam, ذٰلِکَ = "that").
- **PDF Highlight Focus:** The practice-words block, noting familiar words.
- **Expected Outcome:** No hesitation reading a Khari-Zabar as anything other than a plain "aa."
- **Homework:** Re-read practice words.
- **Assessment:** Default criterion.

### Lesson 14 — Khari Zer
- **Qaida Topic:** Khari Zer — compact stand-in for written ی-madd
- **PDF Page:** p.14
- **Objective:** Read the compact "ee"-sound sign, equal to Ya-madd from L11.
- **Prerequisite:** Lesson 13.
- **Next Lesson:** Lesson 15.
- **Duration:** 30 min.
- **Tutor should teach:** Grid; practice words اِلْفِ رُسُلِهٖ عِبَادِهٖ بِهٖ هٰذِهٖ وَقِیْلِهٖ نُوْرِهٖ بِکَلِمَتِهٖ بَایَتِهٖ بِکِتَابِهٖ بِیَمِیْنِهٖ فِیْهِ.
- **Practice Activity:** Student reads all words, noting the very common pronoun-suffix pattern ـهٖ ("his/its").
- **PDF Highlight Focus:** The ـهٖ ending across multiple words — a pattern-recognition win.
- **Expected Outcome:** Student recognizes the ـهٖ pattern on sight in new words later.
- **Homework:** Re-read practice words.
- **Assessment:** Default criterion.

### Lesson 15 — Ulta Pesh
- **Qaida Topic:** Ulta Pesh ("upside-down pesh") — compact stand-in for written و-madd
- **PDF Page:** p.15
- **Objective:** Read the compact "oo"-sound sign, equal to Waw-madd from L12.
- **Prerequisite:** Lesson 14.

### Lesson 37 — Alamat-e-Waqf (full pause-symbol reference)
- **Qaida Topic:** The complete set of Qur'anic pause/stop symbols and what each means
- **PDF Page:** p.37
- **Objective:** Recognize every waqf symbol used in a standard mus'haf and know what to do at each one.
- **Prerequisite:** Lesson 36.
- **Next Lesson:** Review 13.
- **Duration:** 35 min.
- **Tutor should teach:** Go through the full reference table symbol by symbol: **م** (Waqf-e-Laazim — must stop, stopping is essential); **ط** (Waqf-e-Mutlaq — should stop); **ج** (Waqf-e-Ja'iz — permissible to stop, better to); **ز** (stopping is allowed); **ص**/**سکتہ** (a brief pause, no breath break, when needed); **قف** (no harm in pausing here); **لا** (not correct to stop here — mid-meaning); **صلی**/**صلے** (better to continue / better to stop but either is acceptable); **∴ ∴** (the mu'anaqa "two dots twice" — stop at *one* of the two marked spots, not both); **اء** (this ayah's meaning is linked to a symbol that already appeared in the previous ayah). Also cover the closing rule-of-thumb: where multiple marks could apply, follow the one that keeps the breath/sentence sense intact, and if you must break mid-ayah for breath, resume a little before where you stopped.
- **Practice Activity:** Tutor shows a short passage with several different waqf marks (can reuse p.28's Al-Fatiha, now reading it "for real" applying the correct behavior at every mark) and has the student read it applying each symbol correctly.
- **PDF Highlight Focus:** The reference table itself — go mark by mark.
- **Expected Outcome:** Student can name what to do at any of the 8+ waqf marks shown and applies them correctly when re-reading a familiar passage.
- **Homework:** Re-read Surah Al-Fatiha (p.28) applying today's waqf knowledge properly.
- **Assessment:** Student correctly identifies the required action for 6 randomly-shown waqf symbols with ≥5/6 correct.

- **Material:** `Noorani_Qaida.pdf` uploaded once to Supabase Storage; every lesson below references it via a `lesson_materials` row carrying that lesson's specific `page_start`/`page_end` (see `supabase/migrations/0012_lesson_material_page_range.sql`), so opening a lesson's Teach screen jumps straight to the right pages instead of page 1.
- **Lessons:** each of the 39 teaching lessons + 13 review lessons + the final assessment is a real `lessons` row, scheduled sequentially, titled exactly as the headings above (e.g. "Lesson 7 — Zabar (Fatha)"), so `Classes → Qaida – Beginners → Lessons` lists the whole sequence in order.
- **Teach / Sharing screen:** for a lesson whose attached material is a PDF (rather than the bundled-surah ayah data used elsewhere in the app), the Teach screen shows the real PDF via `PdfViewer` at that lesson's page range, and the current page is broadcast live to the student's `/share/[lessonId]` view over the same Realtime channel already used for ayah-sharing — see `docs/PROGRESS.md` for exactly what "highlighting" does and does not cover in this pass.
- **Progress/Notes/Attendance:** used exactly as built in the expanded Phase 1 work — no schema changes needed beyond the page-range columns above.
